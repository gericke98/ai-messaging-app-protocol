    **demo/src/main.rs:**
    Entry point per D-02 pattern (Pattern 3 in RESEARCH.md):
    1. Initialize tracing_subscriber for debug output
    2. Generate two Ed25519 key pairs: one for "alice@demo.ainm.local" (human), one for "helper@demo.ainm.local" (agent)
    3. Start Axum server on 127.0.0.1 with a random available port (use TcpListener::bind("127.0.0.1:0"))
    4. Register both identities with the server's in-memory identity store
    5. Spawn agent::run(server_addr, agent_keys) as tokio task
    6. Spawn repl::run(server_addr, human_keys) as tokio task
    7. Print welcome banner with server address, identities, and instructions
    8. Wait for REPL exit, then abort agent and server tasks

    Module declarations: mod identity, signing, protocol, server, agent, streaming, repl, render.

    **demo/src/identity.rs:**
    - `struct Identity { address: String, key_pair: ring::signature::Ed25519KeyPair, public_key_bytes: Vec<u8> }`
    - `fn generate_keypair(address: &str) -> anyhow::Result<Identity>`: Generate Ed25519 key pair using ring::signature::Ed25519KeyPair::generate_pkcs8(&ring::rand::SystemRandom::new()). Store the PKCS8 document. Extract public key bytes.
    - `struct IdentityRecord { address: String, type_: String, public_key: String, key_id: String, server: String, created_at: String }`: JSON-serializable identity record matching spec/identity.md Section 5.
    - `struct IdentityStore`: In-memory HashMap<String, IdentityRecord> for the demo. Methods: register(address, public_key) -> IdentityRecord, resolve(address) -> Option<IdentityRecord>.
    - Public key encoding: base64url without padding using base64::engine::general_purpose::URL_SAFE_NO_PAD.

    **demo/src/signing.rs:**
    - `fn sign_envelope(key_pair: &Ed25519KeyPair, envelope: &mut serde_json::Value) -> anyhow::Result<String>`: Follows security.md Section 4 exactly: (1) clone envelope, (2) remove "signature" field, (3) canonicalize with serde_json_canonicalizer::to_string, (4) sign canonical UTF-8 bytes with key_pair.sign(), (5) encode as base64url no padding, (6) set envelope["signature"], (7) return signature string.
    - `fn verify_signature(public_key_bytes: &[u8], envelope: &serde_json::Value) -> anyhow::Result<bool>`: (1) clone envelope, (2) extract signature string, (3) remove "signature" field, (4) canonicalize, (5) decode signature from base64url, (6) verify with ring::signature::UnparsedPublicKey::new(&ED25519, public_key_bytes).verify().
    - Per Pitfall 3: use serde_json_canonicalizer for RFC 8785 compliance, never hand-roll canonicalization.

    **demo/src/protocol.rs:**
    - Serde-serializable structs for JSON-RPC 2.0:
      - `JsonRpcRequest { jsonrpc: String, method: String, id: serde_json::Value, params: Option<serde_json::Value> }`
      - `JsonRpcResponse { jsonrpc: String, id: serde_json::Value, result: Option<serde_json::Value>, error: Option<JsonRpcError> }`
      - `JsonRpcNotification { jsonrpc: String, method: String, params: Option<serde_json::Value> }`
      - `JsonRpcError { code: i32, message: String, data: Option<serde_json::Value> }`
    - Helper constructors: `fn new_request(method, params, id)`, `fn new_response(id, result)`, `fn new_error(id, code, message)`, `fn new_notification(method, params)`.
    - AINM message envelope: `MessageEnvelope { id: String, from: String, thread_id: String, timestamp: String, type_: String, content: Vec<serde_json::Value>, signature: String }` with `fn to_value(&self) -> serde_json::Value` and `fn from_value(v: &serde_json::Value) -> Self`.
    - Helper: `fn new_message_id() -> String` using uuid::Uuid::now_v7().
    - Helper: `fn now_rfc3339() -> String` using chrono::Utc::now().to_rfc3339_opts(SecondsFormat::Millis, true).

    **demo/src/server.rs:**
    - Axum router with: GET "/ws" -> WebSocket upgrade handler, GET "/.well-known/ainm/agent-card/helper" -> Agent Card JSON endpoint.
    - WebSocket handler: accept connection, perform initialize/initialized handshake, then loop receiving JSON-RPC messages and dispatching by method:
      - "ainm.message.send": verify signature, store message, route to agent's channel (tokio::sync::broadcast or mpsc), send JSON-RPC response with message_id
      - "ainm.thread.create": create thread in memory, return success
      - "ainm.stream.cancel": forward cancel to agent
      - Unknown method: return JSON-RPC error -32601 "Method not found"
    - Server state (shared via Arc): IdentityStore, thread list, broadcast channels for message routing between human and agent connections.
    - `pub async fn start(identity_store: IdentityStore, agent_card: serde_json::Value) -> anyhow::Result<(SocketAddr, tokio::task::JoinHandle<()>)>`: binds to 127.0.0.1:0, returns the actual bound address and server task handle.
    - Agent Card endpoint serves the JSON from spec/agent-card.md format for "helper@demo.ainm.local".

    All code must compile. Use `anyhow::Result` for error handling throughout. Use tracing::info!/debug!/error! for logging.

    **demo/src/streaming.rs:**
    - `pub async fn send_streamed_response(ws_sender: &mut SplitSink, identity: &Identity, thread_id: &str, text: &str) -> anyhow::Result<()>`:
      1. Generate stream_id and message_id (UUIDv7)
      2. Send StreamStart notification: { method: "ainm.stream.start", params: { stream_id, message_id, from: identity.address, thread_id, timestamp, blocks: [{ index: 0, type: "text", hint: "Response text" }] } }
      3. Split text into word-sized chunks (split on spaces, ~2-5 words per delta)
      4. For each chunk, send StreamDelta notification: { method: "ainm.stream.delta", params: { stream_id, block_index: 0, delta: chunk_text, sequence: N } }
      5. Sleep 30-80ms between deltas (use rand for random delay in range)
      6. After all deltas, construct final TextBlock content, sign the collapsed message, send StreamEnd: { method: "ainm.stream.end", params: { stream_id, message_id, timestamp, final_content: [{ type: "text", version: "1.0", source: "agent", fallback: "...", text: full_text }], signature: sig } }

    **demo/src/repl.rs:**
    - `pub async fn run(server_addr: SocketAddr, identity: Identity) -> anyhow::Result<()>`:
      1. Connect to ws://{server_addr}/ws using tokio-tungstenite
      2. Perform ainm.initialize handshake
      3. Create thread via ainm.thread.create (generate thread_id with UUIDv7)
      4. Split WebSocket into sender/receiver (futures_util::StreamExt)
      5. Spawn a task to listen for incoming messages (agent responses, stream events, tool events) and render them using render module
      6. Run rustyline REPL loop on a spawn_blocking thread:
        - Prompt: "alice> "
        - On each line: construct MessageEnvelope, sign it, send as ainm.message.send JSON-RPC request
        - On "/quit" or Ctrl-C: break loop, send ainm.shutdown
      7. Special commands: "/card" -> fetch and display Agent Card from /.well-known/ainm/agent-card/helper, "/help" -> show available commands

    **demo/src/render.rs:**
    - `pub fn render_message(envelope: &serde_json::Value, verified: bool)`:
      1. Print sender header: "[alice@demo.ainm.local]" or "[helper@demo.ainm.local]" with colored sender name
      2. Print verification badge: green "[VERIFIED]" or red "[FAILED]" based on verified parameter
      3. Print timestamp
      4. For each content block, call render_content_block
    - `pub fn render_content_block(block: &serde_json::Value)`:
      Match on block["type"]:
      - "text": print text content (plain, or use termimad if included)
      - "code": print with language header in dimmed, code in cyan, bordered
      - "button": print "[ label ]" with color based on style (primary=blue, secondary=white, danger=red)
      - "form": print "=== title ===" in yellow, each field as "  label (type): ___"
      - "approval": print "! APPROVAL: prompt !" with options colored by style
      - "table": print column headers and rows in formatted columns
      - default: print fallback text in dimmed
    - `pub fn render_stream_delta(delta: &str)`: print delta text inline (no newline) to show token-by-token arrival. Use print!() not println!().
    - `pub fn render_stream_start(stream_id: &str)`: print dimmed "[streaming...]"
    - `pub fn render_stream_end(verified: bool)`: print newline + verification badge
    - `pub fn render_tool_event(event_type: &str, params: &serde_json::Value)`:
      - "started": print yellow ">> Tool: {tool_name} - {description}"
      - "progress": print dimmed "   {progress_text} [{percent_complete}%]"
      - "completed": print green/red based on status ">> Tool complete: {result_summary} ({duration_ms}ms)"
    - `pub fn render_agent_card(card: &serde_json::Value)`: print formatted Agent Card fields.
    - Use colored crate for all terminal colors. Keep it simple -- no ratatui/crossterm TUI (per anti-pattern in RESEARCH.md).
