### New Integration Findings (Post-Phase 4)

#### INT-01: ainm.initialized handshake step missing (Medium)

**Affected:** TRNS-01, TRNS-04, SPEC-05
**Detail:** `spec/transport.md` Section 4.3 requires clients to send `ainm.initialized` after receiving the init response, and servers MUST reject methods with `-32021` before receiving it. Neither demo client sends this notification; server does not enforce the sequence.
**Impact:** Demo-level gap only. Spec, schema, and AsyncAPI all define the step correctly.

#### INT-02: Agent Card discovery URL non-conformant (Low)

**Affected:** DISC-01, DISC-02, SPEC-05
**Detail:** Spec pattern is `/.well-known/ainm/{name}/agent-card.json`; demo registers `/.well-known/ainm/agent-card/helper` (segments inverted). Internally consistent but third-party clients following the spec would construct the wrong URL.
**Impact:** Demo-level gap only. Spec is correct.
