# Phase 13 -- UI Design Contract

> Visual and interaction contract for the AI-Native Features & Platform phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (native iOS -- shadcn not applicable) |
| Preset | not applicable |
| Component library | SwiftUI native controls (iOS 18+) |
| Icon library | SF Symbols (system-provided) |
| Font | San Francisco (system default via SwiftUI semantic fonts) |

Carries forward from Phase 12. No changes to design system tooling.

## Spacing Scale

Inherited from Phase 12 with one addition: 12pt for component-internal padding.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | Icon gaps, inline padding, mention chip internal padding |
| sm | 8pt | Compact element spacing, tool call indicator row internal |
| md-sm | 12pt | Component-internal padding (tool call indicator, sub-thread indicator leading) |
| md | 16pt | Default element spacing, card padding, section gaps |
| lg | 24pt | Memory panel section padding, agent card detail padding |
| xl | 32pt | Horizontal page margins |
| 2xl | 48pt | Not used in this phase |
| 3xl | 64pt | Not used in this phase |

Exceptions:
- 44pt minimum touch target height for all tappable elements (Apple HIG, carried from Phase 10)
- 36pt avatar diameter (carried from Phase 11)
- 24pt inline avatar in tool call indicators and mention autocomplete rows
- 12pt corner radius for card containers (matches existing message bubble / block radius)
- 60pt skill tag pill minimum width in Agent Card detail view

## Focal Point

Phase 13 introduces five distinct feature areas. Each has its own focal point:

- **Tool visibility:** The collapsed indicator row in the message thread, drawing the eye to what the agent is doing right now.
- **@-mentions:** The autocomplete popup above the composer, demanding immediate input selection.
- **Agent discovery:** The Agent Card list with prominent agent names and descriptions.
- **Memory context:** The context sheet, opened on demand, with the conversation summary as the hero text.
- **Sub-threading:** The branch indicator on the parent message and the banner bar at the top of the sub-thread.

## Component Inventory

### Component 1: ToolCallIndicatorView (AI-01)

**Layout:** Renders inline within the message thread as a child of the message that triggered the tool call. Positioned after the message content blocks but before the next message.

**Collapsed state (default):**
- Full available width, 44pt minimum height
- Background: `Color(.tertiarySystemBackground)`
- Corner radius: 8pt
- Horizontal padding: 12pt, vertical padding: 8pt
- Leading: status icon (SF Symbol, 16pt)
  - Running: `ProgressView()` spinner (14pt), tinted orange
  - Completed: `checkmark.circle.fill`, `Color(.systemGreen)`
  - Error: `xmark.circle.fill`, `Color.red`
  - Timed out: `clock.badge.questionmark`, `Color(.secondaryLabel)`
- Center: tool name in `.subheadline` bold, single line truncated
- Trailing: duration (if completed) in `.caption` regular, `Color(.secondaryLabel)`, formatted per spec Section 5.4
- Trailing (if running): no duration, just spinner
- Chevron: `chevron.right` rotated 90 degrees when expanded, `Color(.tertiaryLabel)`, 12pt

**Expanded state (tap to toggle):**
- Collapsed row stays at top
- Below: expanded detail area with `Color(.secondarySystemBackground)` background
- Corner radius: 0pt top (merges with collapsed row), 8pt bottom
- Padding: 12pt all sides
- Sections separated by 12pt vertical spacing:
  - **Input** (if present): Label "Input" in `.caption` bold. Below: JSON pretty-printed in monospace `.caption` regular on `Color(.tertiarySystemBackground)` with 8pt padding and 6pt corner radius. Max height: 200pt, scrollable.
  - **Progress** (if present): Label "Progress" in `.caption` bold. Below: progress detail text in `.caption` regular. If `total` present: show horizontal `ProgressView(value: current, total: total)` tinted accent.
  - **Result** (if completed): Label "Result" in `.caption` bold. Below: result summary in `.caption` regular.
  - **Error** (if error): Label "Error" in `.caption` bold. Below: error message in `.caption` regular, `Color.red`.
  - **Duration** (if completed): shown in collapsed row; not duplicated here.

**Grouping:** Multiple tool calls from the same message group vertically with 4pt spacing between indicators. Each call_id gets its own ToolCallIndicatorView.

**Timeout behavior:** If a tool call has been running for 5 minutes without a completed event, transition status to "timed out" with clock icon and text "Timed out" in `.caption` regular, `Color(.secondaryLabel)`.

### Component 2: MentionAutocompleteView (AI-02)

**Layout:** Overlay popup anchored above the composer text field. Appears when user types `@` followed by zero or more characters.

**Container:**
- Width: matches composer width minus 32pt (16pt margin each side)
- Max height: 200pt (approximately 4 rows)
- Background: `Color(.systemBackground)`
- Corner radius: 12pt
- Shadow: `.shadow(color: .black.opacity(0.15), radius: 8, y: -4)`
- Border: 0.5pt `Color(.separator)`

**Row layout:**
- Height: 48pt
- Leading: `AvatarView` at 24pt diameter
- 8pt gap
- VStack leading-aligned:
  - Name: `.body` regular, `Color(.label)`, single line truncated
  - Address: `.caption` regular, `Color(.secondaryLabel)`, single line truncated
- Divider: `Color(.separator)` between rows
- Last row: no bottom divider

**Interaction:**
- Typing `@` opens the popup showing all thread participants
- Each additional character filters by display name prefix (case-insensitive)
- Tap a row: insert `@{displayName}` at cursor position, store mention metadata (address, offset, length) in a local mentions array
- Escape/backspace past `@`: dismiss popup
- If zero matches: show "No matches" in `.subheadline` regular, `Color(.secondaryLabel)`, centered, 48pt height

**Mention rendering in sent messages:**
- In TextBlockView, mentions from the `mentions` array are highlighted: `Color.accentColor` foreground, `.body` bold weight
- Tapping a mention: no action in v1 (future: navigate to participant profile)

### Component 3: MentionTextRenderer (AI-02)

**Purpose:** Extends existing TextBlockView to render @-mention spans with highlight styling.

**Algorithm:**
1. Parse markdown to AttributedString (existing logic)
2. Sort mentions by offset descending (to avoid index shifting)
3. For each mention, apply at the character range [offset, offset+length):
   - `.foregroundColor = Color.accentColor`
   - `.font = .body.bold()`
4. Return the composed AttributedString

**Edge cases:**
- Mentions in human bubbles: use `.white` bold instead of accent (on accent background)
- Overlapping mention ranges: last-applied wins (should not happen per spec)
- Mention text does not match text at offset: render without highlight, log warning

### Component 4: AgentDiscoveryView (AI-03)

**Layout:** Full-screen view pushed onto NavigationStack. Accessed from a toolbar button or tab.

**Navigation bar:**
- Title: "Discover Agents"
- Search bar: `.searchable(text:)` modifier, placeholder "Search agents..."

**List layout:**
- Plain list style
- Each row: AgentCardRowView (see below)
- Pull-to-refresh: re-fetches known agent cards with ETag-based conditional requests
- Loading state: `ProgressView` centered

**AgentCardRowView:**
- Height: auto (approximately 80pt)
- Leading: `AvatarView(participantType: "agent", size: 44)` with orange tint
- 12pt gap
- VStack leading-aligned:
  - Name: `.title2` bold, `Color(.label)`, single line truncated
  - Description: `.body` regular, `Color(.secondaryLabel)`, max 2 lines
  - HStack of skill tags (first 3): capsule pills with `Color(.tertiarySystemFill)` background, `.caption` bold text, 4pt vertical padding, 8pt horizontal padding, 4pt spacing between pills
- Trailing: `chevron.right`, `Color(.tertiaryLabel)`, 14pt

**Empty state:**
- Icon: `magnifyingglass` at 48pt, `Color(.tertiaryLabel)`
- Heading: "No agents discovered" in `.title2` bold
- Body: "Connect to an agent by entering their AINM address" in `.subheadline` regular, `Color(.secondaryLabel)`
- CTA: Text field with "agent@server.example" placeholder + "Add Agent" button (accent, `.borderedProminent`)

**Search behavior:**
- Filters locally cached agent cards by name, description, and skill tags
- Case-insensitive substring match

**Header section:**

  - Description: `.body` regular, `Color(.secondaryLabel)`

### Component 6: MemoryContextView (AI-04)

**Layout:** Presented as a sheet from the "Context" pill in the thread toolbar. Half-sheet presentation (`.presentationDetents([.medium, .large])`).

**Context pill (trigger):**
- Position: trailing toolbar item in MessageThreadView
- Appearance: rounded rectangle, `Color.accentColor.opacity(0.12)` background, `Color.accentColor` text
- Label: SF Symbol `brain` + "Context" in `.caption` bold
- Size: auto-width, 28pt height, 8pt horizontal padding, 6pt corner radius
- Only visible when the thread has at least one agent participant

**Sheet content:**

**Section 1: Conversation Summary**
- Section header: "Summary" in `.subheadline` bold
- Body: conversation summary text from context frame, `.body` regular
- If no summary: "No summary available" in `.body` regular, `Color(.secondaryLabel)`

**Section 2: Active Context**
- Section header: "Active Context" in `.subheadline` bold
- Subtitle: "{messageCount} messages from {windowStart}" in `.caption` regular, `Color(.secondaryLabel)`
- List of recent message summaries:
  - Each row: sender name in `.subheadline` bold, summary in `.body` regular, timestamp in `.caption` `Color(.secondaryLabel)`
  - Max 10 rows displayed, scrollable

**Section 3: Archival Facts (preview)**
- Section header: "Archival Facts" in `.subheadline` bold with trailing "View All" button (`.caption` bold, accent color)
- Show first 5 facts as compact rows:
  - Key: `.subheadline` bold
  - Value: `.body` regular, single line truncated
- "View All" navigates to full ArchivalMemoryView

**Participants section:**
- Section header: "Participants" in `.subheadline` bold
- Each participant: HStack with `AvatarView(size: 24)`, name `.subheadline`, presence dot (green = online, gray = offline) 8pt circle

### Component 7: ArchivalMemoryView (AI-05)

**Layout:** Full-screen view pushed from MemoryContextView "View All" or accessible from thread menu.

**Navigation bar:**
- Title: "Archival Memory"
- Search bar: `.searchable(text:)` modifier, placeholder "Search facts..."

**List layout:**
- Plain list style with sections grouped by `storedBy` agent
- Section header: agent name in `.subheadline` bold, `Color(.secondaryLabel)`

**Fact row:**
- VStack leading-aligned with 4pt spacing:
  - Key: `.subheadline` bold, `Color(.label)`
  - Value: `.body` regular, `Color(.label)`, max 3 lines
  - Tags (if present): HStack of capsule pills, `Color(.tertiarySystemFill)` background, `.caption` regular text, 2pt vertical padding, 6pt horizontal padding
  - Metadata: "Stored by {agent} on {date}" in `.caption` regular, `Color(.secondaryLabel)`
- Padding: 12pt vertical, 16pt horizontal

**Swipe-to-delete:**
- Swipe left reveals red "Delete" button
- Tap "Delete": show confirmation alert
  - Title: "Delete Fact"
  - Body: "This will permanently remove this fact from {agent}'s memory."
  - Actions: "Delete" (destructive) and "Cancel"
- On confirm: send `ainm.memory.evict` with `fact_id`, remove row with animation

**Search behavior:**
- Sends `ainm.memory.query` with `query` parameter to server
- Shows loading spinner during search
- Results replace the full list (server-side search)
- Clear search restores locally cached full list

**Empty state:**
- Icon: `brain` at 48pt, `Color(.tertiaryLabel)`
- Heading: "No archival facts" in `.title2` bold
- Body: "This agent hasn't stored any facts yet" in `.subheadline` regular, `Color(.secondaryLabel)`

### Component 8: SubThreadIndicatorView (PLT-04)

**Layout:** Appears as a badge on messages in the parent thread that have sub-threads branching from them.

**Appearance:**
- Position: below the message bubble, left-aligned with 12pt leading padding
- Background: `Color(.tertiarySystemFill)`
- Corner radius: 6pt
- Padding: 4pt vertical, 8pt horizontal
- Content: SF Symbol `bubble.left.and.bubble.right` (12pt, `Color(.secondaryLabel)`) + reply count "{N} replies" in `.caption` bold, `Color.accentColor`
- Tappable: navigates to the sub-thread

**Branch action (creating sub-threads):**
- Long-press context menu on any message: include "Branch Thread" option with SF Symbol `arrow.branch`
- Disabled on messages already in a sub-thread (one level per spec)
- Tapping "Branch Thread" creates a new thread via `ainm.thread.create` with `parentThreadId` and `parentMessageId`, then navigates to it

### Component 9: SubThreadBannerView (PLT-04)

**Layout:** Fixed banner at the top of MessageThreadView when viewing a sub-thread.

**Appearance:**
- Full width, 44pt height
- Background: `Color(.secondarySystemBackground)`
- Bottom border: 0.5pt `Color(.separator)`
- Leading: SF Symbol `arrow.uturn.backward` (14pt, `Color.accentColor`), tappable
- Center: "Thread from {parentMessageSenderName}" in `.subheadline` bold
- Trailing: "View Parent" in `.caption` bold, `Color.accentColor`, tappable

**Interaction:**
- Tap back arrow or "View Parent": pop navigation to parent thread, scroll to the branching message
- Banner does not scroll with content -- pinned at top

### Component 10: DeepLinkHandler (PLT-05)

**URL scheme:** `ainm://`

**Supported routes:**
- `ainm://thread/{thread_id}` -- navigate to thread
- `ainm://thread/{thread_id}/message/{message_id}` -- navigate to thread and scroll to message

**Not-found handling:**
- If thread_id not in local GRDB: show alert "Thread Not Found" with body "This thread is not available on your device." and dismiss "OK"
- If message_id not found in thread: navigate to thread, show transient toast "Message not found" at bottom for 3 seconds

**Integration:**
- `.onOpenURL` in AINMMessengerApp.swift
- Updates `appState.selectedThreadId` and `appState.scrollToMessageId`
- NavigationPath handles the rest via existing navigation infrastructure

## Interaction Contracts

### Tool Call Visibility Interactions

| Interaction | Behavior |
|-------------|----------|
| Tool call started event arrives | ToolCallIndicatorView appears below the triggering message in collapsed state with spinning indicator and tool name |
| Tool call progress event arrives | Updates existing indicator: progress detail text appears, progress bar if total is known |
| Tool call completed event arrives | Indicator transitions to completed: green checkmark, duration badge appears |
| Tool call error event arrives | Indicator transitions to error: red X, error message in expanded detail |
| Tap collapsed indicator | Expands to show input, progress, result/error sections. Chevron rotates 90 degrees. |
| Tap expanded indicator | Collapses back to single row. Chevron rotates back. |
| 5-minute timeout (no completed event) | Status transitions to "timed out" with clock icon. No spinner. |
| Out-of-order events (progress before started) | Buffer for up to 10 seconds. Display from content[] fallback if started never arrives. |

### @-Mention Interactions

| Interaction | Behavior |
|-------------|----------|
| User types "@" in composer | Autocomplete popup appears above composer with all thread participants |
| User types additional characters after "@" | Popup filters by display name prefix, case-insensitive |
| User taps autocomplete row | Popup dismisses. "@{displayName}" inserted at cursor. Mention metadata stored in local array. |
| User backspaces through "@" | Popup dismisses |
| User taps outside popup | Popup dismisses |
| Zero filter matches | Popup shows "No matches" centered text |
| Mention in rendered message | Highlighted in accent blue bold (or white bold in human bubbles) |

### Agent Discovery Interactions

| Interaction | Behavior |
|-------------|----------|
| Open discovery view | Shows locally cached agent cards immediately. Background refreshes with ETag. |
| Search text entered | Filters visible list by name, description, and skill tag substring match |
| Tap agent row | Pushes AgentCardDetailView |
| Tap "Start Conversation" | Creates new thread with agent, navigates to thread |
| Tap "Add Agent" with address | Fetches Agent Card via identity resolution chain. On success: adds to list. On failure: inline error "Could not reach agent at this address". |
| Pull to refresh | Re-fetches all cached agent cards with ETag-based conditional requests |

### Memory Context Interactions

| Interaction | Behavior |
|-------------|----------|
| Tap "Context" pill in toolbar | Opens half-sheet with MemoryContextView |
| Context frame notification arrives | Updates MemoryContextView data silently. Does NOT interrupt current thread view. |
| Tap "View All" in archival section | Pushes ArchivalMemoryView (full screen) |
| Swipe left on fact row | Reveals red "Delete" button |
| Tap "Delete" on swipe | Shows confirmation alert |
| Confirm deletion | Sends `ainm.memory.evict`, removes row with animation |
| Search in archival view | Sends `ainm.memory.query` to server, shows results |
| Clear search | Restores locally cached full list |

### Sub-Threading Interactions

| Interaction | Behavior |
|-------------|----------|
| Long-press message in parent thread | Context menu includes "Branch Thread" option (hidden if already in sub-thread) |
| Tap "Branch Thread" | Creates sub-thread via `ainm.thread.create` with parent fields, navigates to new sub-thread |
| Tap sub-thread badge on parent message | Navigates to the sub-thread |
| Tap back arrow or "View Parent" in sub-thread banner | Pops to parent thread, scrolls to branching message |
| Sub-thread receives new message | Badge on parent message updates reply count |

### Deep Link Interactions

| Interaction | Behavior |
|-------------|----------|
| Open `ainm://thread/{id}` | Navigate to thread. If not found: alert with "Thread Not Found". |
| Open `ainm://thread/{id}/message/{mid}` | Navigate to thread, scroll to message. If message not found: navigate to thread + toast "Message not found". |
| App not running, deep link opened | App launches, onOpenURL fires after initialization, navigates to target |

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Dynamic Type | All text uses SwiftUI semantic styles -- scales automatically |
| Touch targets | 44pt minimum height on all tappable elements (tool indicators, autocomplete rows, agent card rows, fact rows, sub-thread badges, context pill) |
| VoiceOver: tool indicator collapsed | `.accessibilityLabel("{toolName}, {status}")`. Running: `.accessibilityValue("In progress")`. Completed: `.accessibilityValue("Completed in {duration}")`. |
| VoiceOver: tool indicator expand | `.accessibilityHint("Double tap to view details")` |
| VoiceOver: mention in text | Mention text announced naturally as part of message content. Bold styling implies emphasis to VoiceOver. |
| VoiceOver: autocomplete popup | `.accessibilityLabel("Mention suggestions")`. Each row: `.accessibilityLabel("{name}, {type}")`. |
| VoiceOver: agent card row | `.accessibilityLabel("{name}, {description}")`. Skills announced after description. |
| VoiceOver: Start Conversation | `.accessibilityLabel("Start conversation with {agentName}")` |
| VoiceOver: memory fact | `.accessibilityLabel("{key}: {value}")`. Swipe actions announced: "Delete". |
| VoiceOver: context pill | `.accessibilityLabel("View memory context")` |
| VoiceOver: sub-thread badge | `.accessibilityLabel("{N} replies in sub-thread")`, `.accessibilityHint("Double tap to open sub-thread")` |
| VoiceOver: sub-thread banner | `.accessibilityLabel("Sub-thread from {senderName}")`. Back action: `.accessibilityLabel("Return to parent thread")`. |
| VoiceOver: deep link error | Alert announced automatically by SwiftUI |
| Reduced motion | Tool indicator expand/collapse: instant, no animation. Autocomplete popup: instant appear/dismiss. All functional interactions preserved. |
| Color contrast | All semantic colors meet WCAG AA in both light and dark mode. Status colors (orange/green/red) used alongside icons and text labels -- never as sole indicator. |
