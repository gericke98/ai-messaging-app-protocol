Refactor `demo/src/main.rs` to:

1. Add clap derive struct at the top of the file:

```rust
use clap::Parser;

#[derive(Parser)]
#[command(name = "ainm-demo", about = "AINM Protocol Demo")]
struct Cli {
    /// Server mode: human (REPL) or agent (headless)
    #[arg(long)]
    mode: Option<String>,

    /// Local WebSocket port
    #[arg(long, default_value = "8080")]
    port: u16,

    /// Federation relay port (mTLS)
    #[arg(long, default_value = "8443")]
    federation_port: u16,

    /// Server identity domain (e.g., server-a.local)
    #[arg(long)]
    identity: Option<String>,

    /// Path to TLS certificate PEM
    #[arg(long)]
    cert: Option<String>,

    /// Path to TLS private key PEM
    #[arg(long)]
    key: Option<String>,

    /// Path to CA certificate PEM for mTLS verification
    #[arg(long)]
    ca_cert: Option<String>,

    /// Remote server to federate with (e.g., server-b.local:8443)
    #[arg(long)]
    remote: Option<String>,
}
```

2. In `main()`, parse CLI args with `let cli = Cli::parse();`

3. Branch on `cli.mode`:
   - If `cli.mode.is_none()`: run the EXISTING legacy demo code (current `main()` body unchanged). This satisfies D-06 backward compatibility.
   - If `cli.mode == Some("human")` or `Some("agent")`: print a placeholder message `"Federation mode: {mode} (not yet implemented, see plans 02-04)"` and exit with Ok(()). This will be filled in by Plan 04.

4. Move the existing demo logic into a function `async fn run_legacy_demo() -> Result<()>` and call it from the `None` branch. This keeps main.rs clean.

Per D-05: CLI flags are `--mode human|agent`, `--port`, `--federation-port`, `--identity`, `--cert`, `--key`. We add `--ca-cert` and `--remote` as additional needed flags per research.
Per D-06: No flags = legacy demo, federation requires explicit `--mode`.
