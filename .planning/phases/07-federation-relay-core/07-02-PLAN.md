Create `demo/src/tls.rs` with four public functions:

1. `pub fn build_mtls_server_config(ca_cert_path: &str, server_cert_path: &str, server_key_path: &str) -> Arc<rustls::ServerConfig>`:
   - Load CA certs via `CertificateDer::pem_file_iter(ca_cert_path)` collecting into `Vec<CertificateDer<'static>>`
   - Build `RootCertStore` and add all CA certs
   - Build `WebPkiClientVerifier` from the root store using `WebPkiClientVerifier::builder(Arc::new(root_store)).build().unwrap()`
   - Load server cert chain via `CertificateDer::pem_file_iter(server_cert_path)`
   - Load server private key via `PrivateKeyDer::from_pem_file(server_key_path)`
   - Build `ServerConfig::builder().with_client_cert_verifier(client_verifier).with_single_cert(server_certs, server_key)`
   - Set `config.alpn_protocols = vec![b"h2".to_vec(), b"http/1.1".to_vec()]`
   - Return `Arc::new(config)`

2. `pub fn build_mtls_client(ca_cert_path: &str, client_cert_path: &str, client_key_path: &str) -> reqwest::Client`:
   - Load CA PEM bytes with `std::fs::read(ca_cert_path)`
   - Create `reqwest::Certificate::from_pem(&ca_pem)`
   - Load client cert + key PEM bytes, concatenate them (cert first, then key)
   - Create `reqwest::Identity::from_pem(&combined_pem)`
   - Build `reqwest::Client::builder().add_root_certificate(ca_cert).identity(identity).use_rustls_tls().build()`

3. `pub fn compute_cert_fingerprint(der_bytes: &[u8]) -> String`:
   - Compute `ring::digest::digest(&ring::digest::SHA256, der_bytes)`
   - Format as `"sha256:"` + hex-encoded digest bytes (lowercase, no separators)
   - Return the string

4. `pub fn load_cert_der(pem_path: &str) -> Vec<u8>`:
   - Load first cert from PEM file via `CertificateDer::pem_file_iter(pem_path).next()`
   - Return the DER bytes as `Vec<u8>` (via `.to_vec()` or `.as_ref().to_vec()`)
   - This is a helper for computing fingerprints from PEM files

Required imports:
```rust

use rustls::ServerConfig;
use rustls_pki_types::{CertificateDer, PrivateKeyDer};
use std::sync::Arc;
```

Create `demo/certs/generate.sh` bash script that generates all certificates using `openssl` CLI:

```bash
#!/usr/bin/env bash
set -euo pipefail
cd "$(dirname "$0")"

echo "Generating AINM demo federation certificates..."

# 1. Generate CA key and self-signed cert (10 year validity)
openssl genpkey -algorithm ED25519 -out ca-key.pem
openssl req -new -x509 -key ca-key.pem -out ca.pem -days 3650 \
  -subj "/CN=AINM Demo CA/O=AINM/C=US"

# 2. Generate Server A key, CSR, and CA-signed cert
openssl genpkey -algorithm ED25519 -out server-a-key.pem
openssl req -new -key server-a-key.pem -out server-a.csr \
  -subj "/CN=server-a.local/O=AINM Demo/C=US"
openssl x509 -req -in server-a.csr -CA ca.pem -CAkey ca-key.pem \
  -CAcreateserial -out server-a.pem -days 365 \
  -extfile <(printf "subjectAltName=DNS:server-a.local,DNS:server-a,DNS:localhost")
rm -f server-a.csr

# 3. Generate Server B key, CSR, and CA-signed cert
openssl genpkey -algorithm ED25519 -out server-b-key.pem
openssl req -new -key server-b-key.pem -out server-b.csr \
  -subj "/CN=server-b.local/O=AINM Demo/C=US"
openssl x509 -req -in server-b.csr -CA ca.pem -CAkey ca-key.pem \
  -CAcreateserial -out server-b.pem -days 365 \
  -extfile <(printf "subjectAltName=DNS:server-b.local,DNS:server-b,DNS:localhost")
rm -f server-b.csr

rm -f ca.srl
echo "Done. Files: ca.pem ca-key.pem server-a.pem server-a-key.pem server-b.pem server-b-key.pem"
```
