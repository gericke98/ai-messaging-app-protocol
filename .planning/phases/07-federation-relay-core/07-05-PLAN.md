1. Keep generating the initial `thread_id` via `protocol::new_message_id()` for the `ainm.thread.create` request payload (the server needs it as a hint).

2. After sending the create request and receiving the response, parse the response body to extract the server-assigned thread_id. The server response (from server.rs line 685-691) is a JSON-RPC response with shape:
```json
{"jsonrpc": "2.0", "id": 3, "result": {"thread_id": "server-a.local:01JQXYZ...", "created": true}}
```

3. Replace the `if let Some(Ok(Message::Text(_)))` block (lines 62-65) with code that:
   - Receives the response text
   - Parses it as `serde_json::Value`
   - Extracts `result.thread_id` as a string
   - Falls back to the original `thread_id` if parsing fails
   - Logs the federation thread_id

Concrete replacement for lines 62-65:
```rust
let thread_id = if let Some(Ok(Message::Text(resp_text))) = ws_receiver.next().await {
    let resp_str = resp_text.to_string();
    if let Ok(resp) = serde_json::from_str::<serde_json::Value>(&resp_str) {
        resp.get("result")
            .and_then(|r| r.get("thread_id"))
            .and_then(|t| t.as_str())
            .map(|t| t.to_string())
            .unwrap_or_else(|| {
                tracing::warn!("Thread create response missing thread_id, using local ID");
                thread_id
            })
    } else {
        tracing::warn!("Failed to parse thread create response");
        thread_id
    }
} else {
    tracing::warn!("No thread create response received");
    thread_id
};
tracing::info!("Thread created: {}", thread_id);
```

4. The variable `thread_id` after this block must be the federation-formatted string (e.g., `server-a.local:01JQXYZ7K8M3N4P5Q6R7S8T9`). This value flows into `thread_id_clone` (line 79) which is used by `run_repl_loop` for all subsequent `ainm.message.send` calls.

NOTE: The initial `let thread_id = protocol::new_message_id();` on line 50 must remain — it is used in the create request payload. The reassignment happens after the response is received. Make sure the variable is declared with `let` (not `let mut`) initially, then shadow it with the response value.
