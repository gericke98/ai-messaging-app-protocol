    Set $id to "https://ainm.dev/schemas/common.schema.json" (per D-05, canonical URI for $ref resolution -- Pitfall 2).

    Extract these shared definitions into $defs:

    1. **AINMAddress**: type string, pattern "^[a-zA-Z0-9][a-zA-Z0-9._-]{0,63}@[a-zA-Z0-9]([a-zA-Z0-9-]*[a-zA-Z0-9])?(\\.[a-zA-Z0-9]([a-zA-Z0-9-]*[a-zA-Z0-9])?)+$" (from identity.md Section 3.1 -- name: 1-64 alphanumeric/dot/dash/underscore, starts with alphanumeric; provider: valid domain)

    2. **UUIDv7**: type string, pattern "^[0-9a-f]{8}-[0-9a-f]{4}-7[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$" (from identity.md message IDs, threading.md thread_id)

    3. **RFC3339Timestamp**: type string, format "date-time", description "RFC 3339 timestamp with millisecond precision and UTC timezone"

    4. **Ed25519Signature**: type string, description "Base64url-encoded Ed25519 signature (64 bytes, no padding)"

    5. **Ed25519PublicKey**: type string, description "Base64url-encoded Ed25519 public key (32 bytes, no padding)"

    6. **ContentBlockBase**: type object, required ["type", "version", "source", "fallback"], properties: type (string), version (string, pattern "^\\d+\\.\\d+$"), source (string, enum ["user", "agent", "system"]), fallback (string). Per Phase 1 decision: mandatory fallback field on every block.

    7. **MessageEnvelope**: type object, required ["id", "from", "thread_id", "timestamp", "type", "content", "signature"], properties: id ($ref UUIDv7), from ($ref AINMAddress), thread_id ($ref UUIDv7), timestamp ($ref RFC3339Timestamp), type (string), content (array of items $ref ContentBlockBase), signature ($ref Ed25519Signature), optional: parent_id ($ref UUIDv7), metadata (type object)

    8. **JsonRpcRequest**: type object, required ["jsonrpc", "method", "id"], properties: jsonrpc (const "2.0"), method (string), id (oneOf [string, integer]), params (object). From transport.md Section 3.1.

    9. **JsonRpcResponse**: type object, required ["jsonrpc", "id"], properties: jsonrpc (const "2.0"), id (oneOf [string, integer, null]), result (any), error ($ref JsonRpcError). oneOf: has result XOR error.

    10. **JsonRpcError**: type object, required ["code", "message"], properties: code (integer), message (string), data (any). From transport.md Section 3.3.

    11. **JsonRpcNotification**: type object, required ["jsonrpc", "method"], properties: jsonrpc (const "2.0"), method (string), params (object). NOT has id. From transport.md Section 3.2.

    Add top-level title "AINM Protocol - Common Definitions" and description referencing protocol version 0.1.0 (per D-08/D-09).
  </action>

  <action>
    Create 4 domain schema files. Each file MUST have:
    - "$schema": "https://json-schema.org/draft/2020-12/schema"
    - "$id": "https://ainm.dev/schemas/{domain}.schema.json"
    - title and description
    - $defs containing all types for that domain
    - Relative $ref to common.schema.json for shared types (e.g., "$ref": "common.schema.json#/$defs/AINMAddress")

    **schemas/identity.schema.json** -- derive from spec/identity.md inline examples:
    - IdentityRecord: the JSON document at .well-known/ainm/identity/{name} (Section 5). Required fields: address, type (enum: "human", "agent"), server (URI), public_key ($ref Ed25519PublicKey), key_id (string), created_at, updated_at ($ref RFC3339Timestamp). Optional: display_name, avatar_url, previous_keys (array of KeyRotationRecord).
    - RegistrationRequest: params for ainm.identity.register. Required: address ($ref AINMAddress), public_key, proof_of_possession (signature of address string).
    - RegistrationResponse: result of registration. Required: address, key_id, registered_at.
    - KeyRotationRecord: required: key_id, public_key, activated_at, deactivated_at (nullable), overlap_expires_at.
    - WellKnownAINMConfig: the .well-known/ainm/config document. Required: server (WebSocket URL), identity_endpoint, version.

    **schemas/security.schema.json** -- derive from spec/security.md inline examples:
    - SignedMessage: extends MessageEnvelope with signature verification semantics. The schema describes the signing input construction: clone envelope, remove "signature" field, canonicalize per RFC 8785, sign UTF-8 bytes.
    - TrustAnnotation: the source field enum ("user", "agent", "system") with cross-check rules (description only -- JSON Schema can't enforce runtime cross-checking).
    - VerificationResult: type object with fields: valid (boolean), signer ($ref AINMAddress), key_id (string), timestamp ($ref RFC3339Timestamp).
    - SecurityErrorCodes: enum of error codes -32001 to -32013 with descriptions matching security.md and identity.md error tables.

    **schemas/content.schema.json** -- derive from spec/content.md inline examples:
    - TextBlock: allOf ContentBlockBase + required text (string, markdown), type const "text", version const "1.0".
    - CodeBlock: allOf ContentBlockBase + required code (string), language (string), type const "code". Optional: line_numbers (boolean), highlight_lines (array of integers).
    - ImageBlock: allOf ContentBlockBase + required url (string, format uri), type const "image". Optional: alt_text (string), width (integer), height (integer), mime_type (string).
    - FileBlock: allOf ContentBlockBase + required url (string, format uri), filename (string), mime_type (string), size_bytes (integer), type const "file". Optional: digest (string, description "SHA-512 hex digest").
    - ExtensionBlock: allOf ContentBlockBase + required type (string, pattern "^[a-z]+\\.[a-z]+\\.[a-z]" for reverse-domain), data (object). Per Phase 1 decision: reverse-domain namespacing.

    **schemas/transport.schema.json** -- derive from spec/transport.md inline examples:
    - InitializeParams: required: protocol_version (string), client_info (object with name, version), capabilities (ClientCapabilities object).
    - InitializeResult: required: protocol_version, server_info (object with name, version), capabilities (ServerCapabilities object), session_id (string).
    - ClientCapabilities: object with optional boolean fields: streaming, parallelStreaming, memory.conversation, memory.archival (from Phase 2 extensions in transport.md).
    - ServerCapabilities: object with optional boolean fields: streaming, parallelStreaming, memory.conversation, memory.archival, maxContextFrameSize (integer).
    - MessageSendParams: required: thread_id ($ref UUIDv7), content (array of ContentBlockBase), signature ($ref Ed25519Signature). Optional: parent_id ($ref UUIDv7).
    - MessageDeliverNotification: the ainm.message.deliver notification params. Required: message ($ref MessageEnvelope).
    - PresenceUpdateParams: required: thread_id, status (enum: "online", "offline", "available", "busy", "processing"), optional: detail (string).
    - ThreadCreateParams, ThreadJoinParams, ThreadLeaveParams: from transport.md method registry.
    - ErrorResponse: $ref JsonRpcError with documented code ranges (-32001..-32007 identity, -32010..-32013 security, -32020..-32029 transport, -32030..-32039 threading).

    For ALL schemas: extract exact field names, types, and constraints from the inline JSON examples in each spec file. Do not invent fields. If the spec says MUST, make the field required. If the spec says MAY or OPTIONAL, do not make it required.
  </action>
