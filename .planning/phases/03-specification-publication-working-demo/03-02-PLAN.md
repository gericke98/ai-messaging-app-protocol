  <action>
    Create 3 schema files. Each MUST have $schema "https://json-schema.org/draft/2020-12/schema", $id "https://ainm.dev/schemas/{domain}.schema.json", and use relative $ref to common.schema.json.

    **schemas/interactive.schema.json** -- derive from spec/interactive.md:
    - ButtonBlock: allOf ContentBlockBase + type const "button", required: label (string), action_id (string), style (enum: "primary", "secondary", "danger"). Optional: disabled (boolean), confirm (object with title, message strings). Per Phase 2 decision: 3 semantic styles only.
    - FormBlock: allOf ContentBlockBase + type const "form", required: form_id (string), title (string), fields (array of FormField), submit_label (string). Optional: cancel_label (string).
    - FormField: type object, required: field_id (string), label (string), field_type (enum: "text", "textarea", "number", "select", "multiselect", "checkbox", "date", "datetime"). Optional: placeholder (string), required (boolean), default_value, options (array of {value, label} for select/multiselect), validation (object with min, max, pattern, min_length, max_length).
    - TableBlock: allOf ContentBlockBase + type const "table", required: columns (array of {key, label, optional sortable boolean}), rows (array of objects). Optional: caption (string), paginated (boolean), page_size (integer).
    - ApprovalBlock: allOf ContentBlockBase + type const "approval", required: approval_id (string), prompt (string), options (array of {option_id, label, style}), status (enum: "pending", "approved", "rejected", "changes_requested"). Optional: resolved_by ($ref AINMAddress), resolved_at ($ref RFC3339Timestamp), resolution_comment (string). Per Phase 2 decision: server-enforced state machine with immutable terminal states.
    - ActionBlock: type object (NOT allOf ContentBlockBase -- ActionBlock is a response message, not a content block). Required: ref_message_id ($ref UUIDv7), ref_block_index (integer), action_id (string), data (object). Per Phase 2 decision: ActionBlocks are full signed messages visible to all.

    **schemas/streaming.schema.json** -- derive from spec/streaming.md:
    - StreamStart: type object, required: stream_id ($ref UUIDv7), message_id ($ref UUIDv7), from ($ref AINMAddress), thread_id ($ref UUIDv7), timestamp ($ref RFC3339Timestamp), blocks (array of BlockLayoutEntry). Per Phase 2 decision: block layout immutable after stream-start.
    - BlockLayoutEntry: type object, required: index (integer), type (enum: "text", "code"), hint (string). Only TextBlock and CodeBlock are streamable in v1.
    - StreamDelta: type object, required: stream_id ($ref UUIDv7), block_index (integer), delta (string), sequence (integer).
    - StreamEnd: type object, required: stream_id ($ref UUIDv7), message_id ($ref UUIDv7), timestamp ($ref RFC3339Timestamp), final_content (array of items $ref ContentBlockBase), signature ($ref Ed25519Signature). This is the collapse event.
    - CancelStream: type object, required: stream_id ($ref UUIDv7). Client-initiated cancellation.
    - StreamingErrorCodes: description-only enum of -32040 to -32044.

    **schemas/threading.schema.json** -- derive from spec/threading.md:
    - ThreadCreateParams: required: thread_id ($ref UUIDv7), creator ($ref AINMAddress), created_at ($ref RFC3339Timestamp). Optional: title (string), metadata (object).
    - ThreadMetadata: type object with properties: thread_id, title, creator, created_at, participants (array of ThreadParticipant).
    - ThreadParticipant: type object, required: identity ($ref AINMAddress), type (enum: "human", "agent"), joined_at ($ref RFC3339Timestamp), role (enum: "creator", "member").
    - SubThreadCreateParams: required: parent_thread_id ($ref UUIDv7), thread_id ($ref UUIDv7), source_message_id ($ref UUIDv7), creator ($ref AINMAddress). Per Phase 1 decision: one-level nesting only.
    - PresenceUpdate: required: thread_id ($ref UUIDv7), identity ($ref AINMAddress), status (enum: "online", "offline", "available", "busy", "processing"). Optional: detail (string). Per Phase 1 decision: thread-scoped presence.
    - MentionEvent: required: thread_id ($ref UUIDv7), message_id ($ref UUIDv7), mentioned ($ref AINMAddress), by ($ref AINMAddress).
    - ThreadErrorCodes: description-only enum of -32030 to -32039.
  </action>

    **schemas/agent-card.schema.json** -- derive from spec/agent-card.md:
    - AgentCard: the full Agent Card document. Required top-level A2A-compatible fields: name (string), description (string), url (string, format uri), version (string), capabilities (AgentCapabilities). Required AINM extension: ainm (AINMExtensions object). Per Phase 2 decision: A2A superset with AINM extensions under ainm namespace.
    - AgentCapabilities: type object with properties: streaming (boolean), pushNotifications (boolean), stateTransitionHistory (boolean) -- A2A-compatible. Optional AINM-specific nested capabilities.
    - AINMExtensions: type object, required: address ($ref AINMAddress), type (const "agent"), supported_content_types (array of strings), threading_preferences (object with properties: prefers_sub_threads (boolean), max_concurrent_threads (integer)). Optional: tools (array of AgentTool), bridgeType (string), bridgeTarget (string).
    - AgentTool: type object, required: name (string), description (string). Optional: input_schema (object -- JSON Schema for tool input), output_schema (object).
    - AgentCardErrorCodes: description-only enum of -32060 to -32069.

    **schemas/memory.schema.json** -- derive from spec/memory.md:
    - ContextFrame: type object, required: thread_id ($ref UUIDv7), recipient ($ref AINMAddress), timestamp ($ref RFC3339Timestamp), sections (object). Sections: active_context (object), conversation_summary (object), archival_facts (array), participant_context (object). Per Phase 2 decision: 32KB max with 50/20/20/10 budget split (document in description).
    - MemoryStoreParams: required: thread_id ($ref UUIDv7), tier (enum: "conversation", "archival"), key (string), value (any). Optional: ttl (integer, seconds). Per Phase 2 decision: key collision = replacement.
    - MemoryQueryParams: required: thread_id ($ref UUIDv7), tier (enum: "conversation", "archival"). Optional: key (string), query (string for semantic search), limit (integer).
    - MemoryQueryResult: type object, required: facts (array of ArchivalFact). Optional: truncated (boolean).
    - ArchivalFact: type object, required: key (string), value (any), stored_at ($ref RFC3339Timestamp), stored_by ($ref AINMAddress).
    - MemoryEvictParams: required: thread_id ($ref UUIDv7), tier (enum: "conversation", "archival"), key (string).
    - MemoryCapabilities: type object, properties: conversation (boolean), archival (boolean), maxContextFrameSize (integer, default 32768).
    - MemoryErrorCodes: description-only enum of -32050 to -32055.

    **schemas/tool-visibility.schema.json** -- derive from spec/tool-visibility.md:
    - ToolCallStarted: type object, required: call_id (string, description "UUIDv7 with optional tc- prefix"), tool_name (string), thread_id ($ref UUIDv7), from ($ref AINMAddress), timestamp ($ref RFC3339Timestamp). Optional: description (string), input_preview (string).
    - ToolCallProgress: type object, required: call_id (string), thread_id ($ref UUIDv7), timestamp ($ref RFC3339Timestamp). Optional: progress_text (string), percent_complete (number, minimum 0, maximum 100).
    - ToolCallCompleted: type object, required: call_id (string), thread_id ($ref UUIDv7), from ($ref AINMAddress), timestamp ($ref RFC3339Timestamp), status (enum: "success", "error", "cancelled"). Optional: result_summary (string), duration_ms (integer), error_message (string).
    - Per Phase 2 decision: tool events are persistent signed thread messages, so they use MessageEnvelope wrapper with type field set to the event type.

    **schemas/compatibility.schema.json** -- derive from spec/compatibility.md:
    - MCPBridgeConfig: type object, required: bridge_identity ($ref AINMAddress), mcp_server_url (string, format uri), tools (array of MCPToolMapping).
    - MCPToolMapping: type object, required: mcp_tool_name (string), ainm_tool_name (string, description "Preserved verbatim from MCP server per Phase 2 decision"). Optional: description (string), input_schema (object).
    - A2ABridgeConfig: type object, required: bridge_identity ($ref AINMAddress), a2a_agent_url (string, format uri).
    - A2ATaskMapping: type object, required: a2a_task_id (string), ainm_thread_id ($ref UUIDv7). Optional: status_mapping (object describing A2A status to AINM event mapping).
    - BridgeAgentCard: description of how bridge Agent Cards include ainm.bridgeType and ainm.bridgeTarget fields (reference agent-card.schema.json#/$defs/AINMExtensions).
  </action>
