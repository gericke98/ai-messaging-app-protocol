DEBT-11 fix options (pick the SIMPLEST that compiles and works):
- **Option A (preferred — minimal):** Make `subThreadCache` `internal` (or `public`) on the view model and pass the cache dict DIRECTLY as a parameter to MessageGroupView. SwiftUI tracks reads of `@Observable` stored properties. Compute info inside ForEach: `if let info = subThreadCache[message.id] { ... }`. The closure-as-prop pattern is replaced with a value-as-prop pattern.
- **Option B:** Keep the closure but add a `subThreadCacheVersion: Int` `@Observable` integer that's incremented on every `loadSubThreadCache()` call, and pass it to MessageGroupView so the closure invalidation is observable. Less elegant.

Use Option A unless something blocks it (closure has side effects, ABI compat with other call sites, etc.). Option A is the SwiftUI-idiomatic fix.
