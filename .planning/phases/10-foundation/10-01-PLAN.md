  <behavior>
    - JCS: Input `{"b":2,"a":1}` -> Output `{"a":1,"b":2}` (sorted keys)
    - JCS: Input `{"a": true, "b": null, "c": "hello"}` -> Output `{"a":true,"b":null,"c":"hello"}` (no whitespace)
    - JCS: Nested objects sort recursively: `{"z":{"b":2,"a":1},"a":0}` -> `{"a":0,"z":{"a":1,"b":2}}`
    - JCS: Arrays preserve order: `{"a":[3,1,2]}` -> `{"a":[3,1,2]}`
    - JCS: String escaping: tab -> `\t`, newline -> `\n`, control chars -> `\u00XX`
    - JCS: Number serialization: `1.0` -> `1`, `1.5` -> `1.5`, `-0` -> `0`
    - JCS: Unicode strings pass through unescaped (except control chars)
    - Base64url: `Data([0x00])` -> `"AA"` (no padding)
    - Base64url: Standard base64 `+/=` replaced with `-_` and padding stripped
    - Base64url: Round-trip: decode(encode(data)) == data for any input

**JCSCanonicalizer.swift** -- implement RFC 8785 JSON Canonicalization Scheme:

The implementation takes a parsed JSON value (via `JSONSerialization`) and produces the canonical string form. Key requirements from RFC 8785:
1. Object keys sorted by UTF-16 code unit comparison (for ASCII keys, same as standard String sort)
2. No whitespace between tokens
3. Strings escaped per RFC 8785 Section 3.2.2.2 (control chars, backslash, double quote)
4. Numbers serialized per ECMAScript `Number.toString()` (1.0 -> "1", -0 -> "0")
5. `null`, `true`, `false` as literal strings

Add two public entry points:
```swift
struct JCSCanonicalizer {
    /// Canonicalize a JSON Data blob
    static func canonicalize(_ jsonData: Data) throws -> String

    /// Canonicalize an already-parsed JSON value (from JSONSerialization)
    static func canonicalize(_ value: Any) throws -> String
}
```

Use the code pattern from 10-RESEARCH.md's JCS section as the starting point. Pay special attention to:
- `NSNumber` bridging: Swift `Bool` and `Int` both bridge to `NSNumber`. Use `objCType` to distinguish booleans from numbers. Check `CFBooleanGetTypeID()` for reliable bool detection.
- String escaping: escape `\b` (0x08), `\t` (0x09), `\n` (0x0A), `\f` (0x0C), `\r` (0x0D), `\"` (0x22), `\\` (0x5C), and all control chars 0x00-0x1F as `\uXXXX`.

**Base64url.swift** -- Data extension for RFC 4648 Section 5:
```swift
extension Data {
    func base64urlEncodedString() -> String {
        base64EncodedString()
            .replacingOccurrences(of: "+", with: "-")
            .replacingOccurrences(of: "/", with: "_")
            .replacingOccurrences(of: "=", with: "")
    }

    init?(base64urlEncoded string: String) {
        var base64 = string
            .replacingOccurrences(of: "-", with: "+")
            .replacingOccurrences(of: "_", with: "/")
        let remainder = base64.count % 4
        if remainder > 0 {
            base64 += String(repeating: "=", count: 4 - remainder)
        }
        self.init(base64Encoded: base64)
    }
}
```

Also add to `Curve25519.Signing.PublicKey` extension (for later use):
```swift
extension Curve25519.Signing.PublicKey {
    var base64urlString: String {
        rawRepresentation.base64urlEncodedString()
    }
}
```
