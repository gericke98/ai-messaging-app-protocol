## Decisions Made
- **Raw Security framework over KeychainAccess:** KeychainAccess 4.2.2 (last updated 2020) has known Swift 6 Sendable issues. Implemented a thin 3-function wrapper (save/load/delete) using SecItemAdd/SecItemCopyMatching/SecItemDelete directly.
- **InMemoryStorage for tests:** Keychain is unavailable in some test contexts. Protocol-based storage injection allows unit tests to run without Keychain access.
- **Randomized Ed25519 awareness:** Apple CryptoKit uses randomized Ed25519 (signatures differ per call for same input). Cross-platform validation verifies Rust signatures in Swift and Swift signatures verify against the same key, rather than comparing signature bytes directly.
