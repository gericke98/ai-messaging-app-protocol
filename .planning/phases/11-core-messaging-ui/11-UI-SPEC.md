# Phase 11 -- UI Design Contract

> Visual and interaction contract for the Core Messaging UI phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (native iOS -- shadcn not applicable) |
| Preset | not applicable |
| Component library | SwiftUI native controls (iOS 18+) |
| Icon library | SF Symbols (system-provided) |
| Font | San Francisco (system default via SwiftUI semantic fonts) |

---

## Spacing Scale

Declared values (must be multiples of 4). Matches Phase 10 established patterns from OnboardingView.swift.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | Label-to-field gaps, inline icon padding, grouped message intra-spacing |
| sm | 8pt | Compact element spacing, info row gaps, list row internal padding |
| md | 16pt | Default element spacing, form field gaps, message bubble padding |
| lg | 24pt | Section padding, gap before primary CTA, conversation list section insets |
| xl | 32pt | Horizontal page margins, top/bottom safe area padding |
| 2xl | 48pt | Empty state vertical centering offset |
| 3xl | 64pt | Not used in this phase |

Exceptions:
- 44pt minimum touch target height for all tappable elements (Apple HIG, established in Phase 10)
- 36pt avatar diameter for conversation list rows and message thread avatars
- 300pt maximum height cap for ImageBlock rendering (D-09)
- 12pt corner radius for message bubbles (human chat bubbles)

---

## Typography

All sizes use SwiftUI semantic text styles for automatic Dynamic Type support. Concrete point sizes listed are the default (Large) size class.

| Role | SwiftUI Style | Default Size | Weight | Line Height |
|------|---------------|-------------|--------|-------------|
| Body | `.body` | 17pt | regular (400) | 1.47 (22pt leading) |
| Label | `.subheadline` | 15pt | regular (400) | 1.33 (20pt leading) |
| Heading | `.title2` | 22pt | bold (700) | 1.27 (28pt leading) |
| Caption | `.caption` | 12pt | regular (400) | 1.33 (16pt leading) |

Additional type roles specific to messaging:

| Role | SwiftUI Style | Default Size | Weight | Usage |
|------|---------------|-------------|--------|-------|
| Code | `.system(.body, design: .monospaced)` | 15pt | regular (400) | CodeBlock content |
| Timestamp | `.caption` | 12pt | regular (400) | Message timestamps, relative dates |
| Agent Badge | `.caption` | 12pt | bold (700) | "Agent" type label next to agent name |
| Sender Name | `.subheadline` | 15pt | bold (700) | Participant name above message |

Weights used: regular (400) + bold (700). Two weights only.

## Color

This phase uses SwiftUI semantic colors exclusively for automatic light/dark mode support (D-14). No hardcoded hex values.

| Role | Light Value | Dark Value | SwiftUI Token | Usage |
|------|-------------|------------|---------------|-------|
| Dominant (60%) | #FFFFFF | #000000 | `Color(.systemBackground)` | Full-screen background, thread background |
| Secondary (30%) | #F2F2F7 | #1C1C1E | `Color(.secondarySystemBackground)` | Agent message background, conversation list rows on selection, code block background override below |
| Accent (10%) | System Blue | System Blue | `Color.accentColor` | See reserved list below |
| Destructive | System Red | System Red | `Color.red` | Error text, disconnect actions |

**Accent reserved for (exhaustive list):**
1. Human message chat bubble background (right-aligned, D-01)
2. Send button in composer (D-12)
3. "Start a Conversation" CTA button (D-07)
4. "Connect" button on onboarding (existing Phase 10)
5. Unread badge dot on conversation list rows
6. "+" new thread button in navigation bar (D-04)

**Additional semantic colors:**

| Token | SwiftUI Value | Usage |
|-------|---------------|-------|
| Secondary text | `Color.secondary` | Timestamps, message previews, info labels |
| Agent message bg | `Color(.secondarySystemGroupedBackground)` | Agent message flat container background (D-01) |
| Code block bg | `Color(.tertiarySystemBackground)` | Dark-toned code block background |
| Separator | `Color(.separator)` | Conversation list row dividers |
| Connection green | `Color.green` | Connected status indicator (D-13) |
| Connection yellow | `Color.yellow` | Reconnecting status indicator (D-13) |
| Connection red | `Color.red` | Offline status indicator (D-13) |
| Human bubble text | `Color.white` | Text on accent-colored human bubbles |
| Agent bubble text | `Color(.label)` | Text on agent message containers |

## Component Inventory

### Screen 1: Conversation List (MSG-01, D-05, D-06, D-07)

**Layout:** NavigationStack root. Full-width List with conversation rows sorted by most recent activity. Primary visual anchor: thread title text (.subheadline bold) in the topmost conversation row.

**Conversation Row:**
- Leading: 36pt avatar circle (SF Symbol `person.fill` for humans, `cpu.fill` for agents, with background tint)
- Center stack (vertical): thread title (.subheadline, bold), last message preview (.caption, secondary color, 2-line max truncation), relative timestamp (.caption, secondary color, trailing-aligned)
- Trailing: unread badge (8pt blue dot) when unread count > 0
- Row height: automatic, minimum 64pt
- Tap: push to message thread (Screen 2)

**Navigation Bar:**
- Title: "Conversations"
- Subtitle: connection status indicator (D-13) -- green/yellow/red dot + text, fades after 5s when connected
- Trailing button: "+" (SF Symbol `square.and.pencil`) to create new thread (D-04)

**Empty State (D-07):**
- Centered vertically
- SF Symbol `bubble.left.and.text.bubble.right` at 60pt, accent color
- Heading: "No conversations yet"
- Body: "Start a conversation with humans or AI agents"
- CTA button: "Start a Conversation" (.borderedProminent, 44pt height, full width minus 32pt margins)

**Pull-to-refresh:** Standard SwiftUI `.refreshable` modifier to re-sync thread list from server.

### Screen 2: Message Thread (MSG-02, MSG-03, MSG-04, D-01, D-02, D-03)

**Layout:** Pushed via NavigationStack. ScrollView with LazyVStack for paginated messages.

**Navigation Bar:**
- Back button (automatic)
- Title: thread title
- Subtitle: participant count (e.g., "3 participants")

**Message Rendering -- Human Messages (D-01):**
- Right-aligned chat bubble with accent background, white text
- Rounded corners: 12pt, bottom-right corner 4pt (tail effect)
- Maximum width: 75% of screen width
- Sender name above first message in group (.subheadline, bold) -- omitted for consecutive same-sender (D-03)
- Timestamp on last message in group (.caption, secondary color, right-aligned below bubble)

**Message Rendering -- Agent Messages (D-01):**
- Left-aligned, full-width flat container
- Background: `Color(.secondarySystemGroupedBackground)` with 12pt corner radius
- Agent badge: SF Symbol `cpu.fill` + agent name (.subheadline, bold) + "Agent" label (.caption, bold, secondary color) per D-02
- Content blocks render full-width inside container
- Timestamp on last message in group (.caption, secondary color, left-aligned below container)

**Message Grouping (D-03):**
- Consecutive messages from same sender grouped
- Avatar + name shown only on first message in sequence
- 4pt vertical spacing between grouped messages
- 16pt vertical spacing between different sender groups
- Timestamp shown only on last message in each group

**Pagination:**
- Initial load: 50 most recent messages (per success criteria)
- Scroll-up to top triggers load-more (prepend older 50 messages)
- Loading indicator: ProgressView centered at top of list while fetching
- ScrollViewReader to maintain scroll position when prepending

**Scroll Behavior:**
- Auto-scroll to bottom on new incoming message (only if already at bottom)
- If user has scrolled up, show "New messages" pill at bottom to jump down

### Screen 2a: Composer (D-12, MSG-03)

**Layout:** Fixed at bottom of message thread, above safe area.

**Components:**
- Auto-growing TextField: placeholder "Message...", grows from 1 line to 4 lines max
- Send button: SF Symbol `arrow.up.circle.fill`, 32pt, accent color, trailing position
- Send button disabled (secondary color) when text field is empty
- Background: `Color(.systemBackground)` with top border `Color(.separator)` at 0.5pt
- Horizontal padding: 16pt. Vertical padding: 8pt.

**Behavior:**
- Return key inserts newline (not send)
- Send on button tap only
- Text cleared after successful send
- Disabled state when offline (entire composer grayed, placeholder: "Offline -- messages will send when reconnected")

### Screen 3: New Thread Composer (D-04, MSG-08)

**Layout:** Modal sheet presented from "+" button.

**Components:**
- "To:" field with @-mention autocomplete for participants
- Autocomplete dropdown: rows with avatar + name + type badge (human/agent)
- Selected participants as chips/tags in the To field
- Message text field (same as Screen 2a composer)
- Navigation bar: "Discard" (leading), "New Conversation" title, no trailing

**Behavior:**
- Thread created on first message send via `thread.create` protocol message
- Dismiss modal after successful send, push to new thread

### Content Block Components (MSG-04, MSG-05, MSG-06, MSG-07)

**TextBlock (MSG-03):**
- Rendered Markdown via `AttributedString(markdown:)` (iOS 15+ native)
- Supports: bold, italic, code spans, links, lists
- Links tappable, open in SFSafariViewController
- Font: .body (17pt) for agent messages, .body with white foreground for human bubbles

**CodeBlock (MSG-05, D-08):**
- Container: full available width, `Color(.tertiarySystemBackground)` background, 8pt corner radius
- Header row: language label (.caption, bold, secondary color) left-aligned, "Copy" button (.caption, accent color) right-aligned
- Code content: monospaced font (.system(.body, design: .monospaced), 15pt), horizontal scroll for long lines
- Syntax highlighting: regex-based `AttributedString` coloring for keywords, strings, comments, numbers
- Languages: Swift, Python, JavaScript, TypeScript, Rust, Go, Java, JSON, HTML, CSS
- Vertical padding: 12pt. Horizontal padding: 16pt.
- Copy button action: copies code text to `UIPasteboard.general`, shows brief "Copied!" toast (1.5s)

**ImageBlock (MSG-06, D-09):**
- Aspect-fit scaling to full message width
- Maximum height: 300pt (D-09)
- Pre-set frame from server-provided width/height to prevent layout jumps
- Placeholder: `Color(.tertiarySystemFill)` rectangle with SF Symbol `photo` while loading
- Corner radius: 8pt
- Tap: full-screen overlay with pinch-to-zoom (NavigationStack push to fullscreen view with `.ignoresSafeArea()`)
- Loading: AsyncImage with progressive loading

**FileBlock (MSG-07, Claude's Discretion):**
- Container: rounded rectangle border (1pt, `Color(.separator)`), 8pt corner radius, 12pt padding
- Leading: SF Symbol `doc.fill` at 28pt, secondary color
- Center stack: filename (.subheadline, bold, primary color), file size (.caption, secondary color, formatted as KB/MB/GB)
- Trailing: SF Symbol `arrow.down.circle` at 24pt, accent color (download button)
- Tap anywhere on row: initiate download via share sheet (`UIActivityViewController`)
- Download state: replace arrow icon with ProgressView while downloading, checkmark when complete

**Fallback Block (unrecognized types):**
- Render `fallback` field as plain text
- Styled as TextBlock with `.secondary` foreground color
- No special formatting

## Interaction Contracts

### Conversation List Interactions

| Interaction | Behavior |
|-------------|----------|
| Tap row | Push to message thread (NavigationStack) |
| Pull down | Refresh thread list from server |
| Tap "+" | Present new thread composer as sheet |
| Swipe (future) | Not implemented in Phase 11 |

### Message Thread Interactions

| Interaction | Behavior |
|-------------|----------|
| Scroll up to top | Load 50 older messages, prepend with scroll position maintained |
| Tap "New messages" pill | Smooth scroll to bottom of thread |
| Tap image | Push to fullscreen image viewer with pinch-to-zoom |
| Tap code "Copy" | Copy code to clipboard, show "Copied!" toast |
| Tap file row | Present UIActivityViewController share sheet |
| Tap link in text | Open in SFSafariViewController |
| Tap send button | Sign message with Ed25519, send via WebSocket, append to thread |

### Offline Behavior (PLT-02, Claude's Discretion)

| State | Behavior |
|-------|----------|
| App launch offline | Show conversation list from GRDB cache. No refresh indicator. |
| Connection lost mid-use | Connection status shows "Offline" (D-13). Composer disabled with offline placeholder. Thread content remains visible from cache. |
| Reconnection | Connection status shows "Reconnecting...", then "Connected" (fades after 5s). Composer re-enabled. New messages sync and appear. |
| Cached vs live | No visual distinction between cached and live messages. All messages come from GRDB (write-through cache pattern). Stale data is acceptable for v1. |

### Unread Badge Logic (Claude's Discretion)

| Rule | Detail |
|------|--------|
| Increment | New message arrives for a thread the user is NOT currently viewing |
| Clear | User navigates into the thread (push to message thread screen) |
| Display | Blue 8pt dot on conversation list row, no numeric count for v1 |
| Persistence | Stored in GRDB (boolean `hasUnread` on ThreadRecord) |

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Dynamic Type | All text uses SwiftUI semantic styles -- scales automatically |
| Touch targets | 44pt minimum height on all tappable elements (Apple HIG) |
| VoiceOver labels | All SF Symbol icons get `.accessibilityLabel()` (e.g., "Send message", "Copy code", "Download file") |
| Color contrast | SwiftUI semantic colors meet WCAG AA in both light and dark mode |
| Reduced motion | No custom animations in Phase 11 that need `accessibilityReduceMotion` gating |
