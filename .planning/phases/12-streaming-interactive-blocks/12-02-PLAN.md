**ButtonBlockView.swift** (UI-SPEC Component 5):
```swift
struct ButtonBlockView: View {
    let content: ContentBlock.ButtonContent
    var onAction: ((_ actionId: String, _ data: [String: Any]) -> Void)? = nil
    @State private var isSending = false
    @State private var showConfirmation = false
```
- Full-width button, 44pt height, 10pt corner radius
- Style mapping: `"primary"` -> accent bg/white text, `"secondary"` -> secondarySystemFill bg/label text, `"danger"` -> red bg/white text
- Disabled state (content.disabled == true OR isSending): tertiarySystemFill bg/tertiaryLabel text
- `.body` bold label centered
- Tap: if `confirmation` non-nil, show `.confirmationDialog` with confirmation text, "{label}" proceed and "Go Back" dismiss. If nil, call action immediately.
- On action: set `isSending = true`, replace label with `ProgressView()` (14pt frame), call `onAction?(content.actionId, [:])`, then disable permanently.
- VoiceOver: `.accessibilityLabel(content.label)`, `.accessibilityHint("Double tap to \(content.label)")`. Disabled: `.accessibilityAddTraits(.isNotEnabled)`.
