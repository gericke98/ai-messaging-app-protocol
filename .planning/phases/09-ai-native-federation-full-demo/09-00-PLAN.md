**Section 5.6 Context Push:**

Follow the exact same documentation pattern as Section 5.5 (Backfill). Include:

1. **Opening paragraph:** "The origin server pushes active context frames to remote servers when a remote agent joins a federated thread, via the `ainm.context-push` method on the relay endpoint. This ensures agents receive memory context immediately without a cold start. See memory.md for context frame format."

2. **Request example** (JSON-RPC 2.0):
```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "ainm.context-push",
  "params": {
    "thread_id": "messaging.example.com:019580a0-1234-7000-8000-000000000001",
    "context_frames": [
      {
        "frame_type": "active_context",
        "key": "user_preferences",
        "data": { "language": "en", "timezone": "America/Los_Angeles" },
        "timestamp": "2026-03-28T12:30:00.000Z"
      }
    ],
    "from_server": "messaging.example.com",
    "server_signature": "c2VydmVyLXNpZ25hdHVyZS1vZi1jb250ZXh0LXB1c2g..."
  }
}
```

3. **Parameters:**
- `thread_id` (string, REQUIRED): Thread ID for which context frames are being pushed.
- `context_frames` (array, REQUIRED): Array of active context frame objects. Each frame contains `frame_type` (string), `key` (string), `data` (object), and `timestamp` (string, RFC 3339).
- `from_server` (string, REQUIRED): The originating server's identifier.
- `server_signature` (string, REQUIRED): Base64url-encoded Ed25519 signature of the JCS-canonicalized `params` (with `server_signature` excluded). Same signing convention as ainm.relay.

4. **Response example:**
```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "result": {
    "accepted": true
  }
}
```

5. **Validation:** "Context push requests are validated at Layer 2 only (server signature). Per-message signature validation (Layer 3) does not apply -- context frames are server-originated operational data, not participant messages. Replay protection (Layer 0) and mTLS (Layer 1) apply as with all relay endpoint methods."

6. **Authorization:** "The pushing server MUST be the origin server for the specified thread (determined by the domain prefix in `thread_id`). Requests from non-origin servers are rejected with error code `-32025` (NotAParticipant)."

7. **Triggering:** "The origin server SHOULD push context frames when: (a) a remote server first participates in a thread, and (b) when new memory is stored in a federated thread. Only active context frames are pushed -- conversation history and archival data are available via `ainm.backfill`."

**schemas/transport.schema.json -- Add ContextPushParams and ContextPushResult:**

Add two new `$defs` entries after `BackfillResult` and before `TransportErrorCodes`:

```json
"ContextPushParams": {
  "type": "object",
  "description": "Parameters for ainm.context-push (origin server -> remote server via HTTP POST). See transport.md Section 5.6.",
  "required": ["thread_id", "context_frames", "from_server", "server_signature"],
  "properties": {
    "thread_id": {
      "type": "string",
      "description": "Thread ID for which context frames are being pushed."
    },
    "context_frames": {
      "type": "array",
      "items": {
        "$ref": "#/$defs/ContextFrame"
      },
      "minItems": 1,
      "description": "Array of active context frames to deliver to the remote server."
    },
    "from_server": {
      "type": "string",
      "description": "Origin server's identifier (matches server_id in server identity response)."
    },
    "server_signature": {
      "type": "string",
      "description": "Base64url-encoded Ed25519 signature of JCS-canonicalized params (with server_signature excluded)."
    }
  }
},
"ContextFrame": {
  "type": "object",
  "description": "A single context frame representing active memory state. See memory.md.",
  "required": ["frame_type", "key", "data", "timestamp"],
  "properties": {
    "frame_type": {
      "type": "string",
      "enum": ["active_context"],
      "description": "Frame type. Currently only 'active_context' is supported for context-push."
    },
    "key": {
      "type": "string",
      "description": "Identifier for this context frame (e.g., 'user_preferences', 'conversation_summary')."
    },
    "data": {
      "type": "object",
      "description": "The context frame data. Structure depends on key."
    },
    "timestamp": {
      "type": "string",
      "format": "date-time",
      "description": "RFC 3339 timestamp when this context frame was created or last updated."
    }
  }
},
"ContextPushResult": {
  "type": "object",
  "description": "Response to ainm.context-push. See transport.md Section 5.6.",
  "required": ["accepted"],
  "properties": {
    "accepted": {
      "type": "boolean",
      "description": "True if context frames were accepted for delivery to local agents."
    }
  }
}
```
