<objective>
Enable memory context propagation across federation boundaries so agents on remote servers receive active context frames immediately when they join a federated thread.

Purpose: Agents need context to provide meaningful responses. Without context-push, a remote agent starts cold with no knowledge of the conversation's memory state. This is the key differentiator that makes AINM agents smarter than generic federated bots.

Output: ainm.context-push handler in relay_handler, context frame assembly and push trigger in server.rs, headless agent context frame processing.
</objective>

```rust
"ainm.context-push" => {
    // D-09: Server-level signature verification only (Layer 2).
    // No per-message signatures needed -- server-to-server operation.
    // Layer 2 verification already done above for all methods.

    let params = match body.get("params") {
        Some(p) => p.clone(),
        None => {
            return (
                StatusCode::OK,
                Json(protocol::new_error(id, -32602, "Missing params")),
            );
        }
    };

    let thread_id = params.get("thread_id").and_then(|t| t.as_str()).unwrap_or("");
    let frames = params.get("context_frames").and_then(|f| f.as_array());

    if thread_id.is_empty() || frames.is_none() {
        return (
            StatusCode::OK,
            Json(protocol::new_error(id, -32602, "Missing thread_id or context_frames")),
        );
    }

    tracing::info!(
        "[federation] Received context-push for thread {} with {} frames",
        thread_id,
        frames.unwrap().len()
    );

    // Deliver context frames to local participants via broadcast channel
    // Use ainm.context.frame method so REPL/agents can render them
    let deliver = serde_json::json!({
        "jsonrpc": "2.0",
        "method": "ainm.context.frame",
        "params": params,
    });
    let _ = state.local_delivery_tx.send(serde_json::to_string(&deliver).unwrap());

    return (
        StatusCode::OK,
        Json(protocol::new_response(id, serde_json::json!({"accepted": true}))),
    );
}
```

**server.rs — Push context frames when a remote server participates in a thread:**

Find where the server handles federation thread creation or where remote servers are added to threads. The trigger point is when the origin server creates a thread and pre-populates remote servers via `thread_registry.add_server()`.

In the `ainm.thread.create` handler in `handle_human_connection`, after the thread is created and remote servers are added, add context-push logic:

```rust
// After thread creation with federation, push context frames to remote servers
if let Some(ref fed) = state.federation {
    // Assemble active context frames from archival store
    let store = archival_store.lock().await;
    if !store.is_empty() {
        let context_frames: Vec<serde_json::Value> = store.iter().map(|(key, value)| {
            serde_json::json!({
                "frame_type": "active_context",
                "thread_id": thread_id,
                "key": key,
                "data": value,
                "timestamp": protocol::now_rfc3339()
            })
        }).collect();

        // Push to all remote participating servers
        if let Some((_, remotes)) = fed.thread_registry.get_info(&thread_id) {
            for remote in &remotes {
                if remote != &fed.server_id {
                    let push_payload = serde_json::json!({
                        "jsonrpc": "2.0",
                        "method": "ainm.context-push",
                        "id": protocol::new_message_id(),
                        "params": {
                            "thread_id": thread_id,
                            "context_frames": context_frames
                        }
                    });
                    fed.relay_sender.enqueue(remote, push_payload);
                    tracing::info!("[federation] Pushed {} context frames to {}", context_frames.len(), remote);
                }
            }
        }
    }
}
```
